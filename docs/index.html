SF-AirPlay D07 - Working 15-Band EQ

Browser-based AirPlay USB DAC firmware installer.

ESP32-S3 N16R8 ONLY. Includes the hardware-tested D07 + 15-band EQ application and an integrated SPIFFS image. The complete browser installation package has not yet been hardware-tested. A clean installation may erase saved Wi-Fi settings, EQ settings, and other device data. This package uses a 16MB flash layout, 3MB OTA app slots and storage at 0x620000. Use the programming/UART port and appropriate USB host power protection. Do not install onto other ESP32 models.

Requirements

Generic ESP32-S3 with 16MB flash and 8MB octal PSRAM, Audiocular D07 USB audio DAC, safe host VBUS and USB-C source CC wiring, data-capable programming cable, Chrome or Edge desktop browser.

Install

Connect your ESP32-S3 programming/UART port to your computer. Disconnect external DAC power while programming. Click Install, select the ESP32 serial port and follow the prompts.

Use a Chromium-based desktop browser supporting Web Serial (Chrome or Edge).

After flashing

Configure Wi-Fi using the AirPlay firmware's setup process. Connect the DAC only after verifying VBUS current limiting, power-path isolation and USB-C CC source configuration. The onboard OTG port and external GPIO19/GPIO20 breakout share the native USB bus; swapping the DAC connector has not been validated.
