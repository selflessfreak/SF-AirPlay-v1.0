ⓘ Important — read before flashing

  • ESP32-S3 N16R8 only: 16 MB flash, 8 MB octal PSRAM, with compatible USB-OTG/D07 wiring and protected host power.
  • The browser installation package has not yet been fully hardware-validated. Firmware includes a proven AirPlay + 15-band EQ application, but its complete flashing package requires validation.
  • A clean installation may erase saved Wi-Fi credentials, EQ presets, and other settings. Keep a known-good firmware backup.
  • Use a data-capable USB cable and the programming/UART port; disconnect external DAC power while programming.
  • Close other serial monitoring tools before installing. Do not connect two independent 5V supplies together.
